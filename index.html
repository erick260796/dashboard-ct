Publish this data for everyone

Right now only you can see the new numbers. To update the website for everyone:

  1. Click Download data.json below. The file holds task counts per technician only, with no customer details.
  2. If your computer renames it to data (1).json, rename it back to data.json.
  3. On GitHub, open the dashboard-ct repository, choose Add file → Upload files, drop data.json and click Commit changes.
  4. Wait 1–2 minutes. Everyone who opens the link sees the new data.

Never upload the Excel files themselves to GitHub. They contain customer names, phone numbers and addresses, and the repository is public.
